# FandomPromoCardMaker 利用規約
最終更新日: 2026/10/26

【1.概要】
  皆さまのオススメ小説をSNSで布教する際に、ちょっと文面を豪華にする用の画像を生成します。
  HTML自体はAIを活用しながら作成しておりますが、背景デザインは「つじ みやび」が作成したものでAIを使用しておりません。
  書影を反映させることが可能ですが、著作権などご注意いただければと思います。

【2.使用方法】
  ・表示される１～３の項目を入力してください。項目が入力されると、自動でテンプレートへ反映されます。
    書影が選択されると、書影に合わせてデザインの色が変更されます。
  ・あらすじ・オススメポイントに関しては、分量により文字サイズを変更された方が視認性が上がる可能性がございます。
    必要に応じて、文字サイズ・位置の調整から修正してください。
  ・背景デザインの色は任意の色へ修正することも可能です。
    必要に応じて、色から修正してください。
  ・「PNGを保存」が選択されると、PCであればダウンロードされます。
    スマートフォンの場合は画像保存用に別ウィンドウが開きますので、長押しし端末へ保存してください。

【3.動作環境】
  以下環境での動作確認済。
  ・Windows 11 以上
  ・iOS 27.0.1 以上
